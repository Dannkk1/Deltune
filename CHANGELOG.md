# Changelog

## 0.1.0 — Initial preview

- Native Qt 6 interface for CachyOS / Arch Linux.
- Device and onboard-profile selection through ratbagd API v2.
- DPI-stage editing and activation using driver-reported values.
- Button remapping, special mouse actions, and keyboard shortcuts.
- Last-left-click protection, asynchronous failure monitoring, and readback.
- Per-user installation and application-menu launcher.
- Backend and offscreen UI tests with GitHub Actions configuration.

Hardware validation is pending. Wireless support depends on the installed
kernel, libratbag, receiver, and firmware. This release does not include G-Shift
layers, RGB, or automatic per-game profiles.
